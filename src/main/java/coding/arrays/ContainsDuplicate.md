# Contains Duplicate

Given an integer array `nums`, return `true` if any value appears more than once in the array; otherwise return `false`.

### Examples

**Example 1**

Input:
```text
nums = [1, 2, 3, 3]
```

Output:
```text
true
```

**Example 2**

Input:
```text
nums = [1, 2, 3, 4]
```

Output:
```text
false
```
